# XS Prospecção — Clone Completo

Sistema completo de prospecção de clientes para desenvolvedores, agências e profissionais de vendas digitais.

---

## 🚀 Como Executar Localmente (1 Clique)

1. Vá até a pasta do projeto:  
   `C:\Users\rhena\Downloads\XS_PROSPECCAO_CLONE`
2. Dê **dois cliques** no arquivo:
   `INICIAR_SISTEMA.bat`
3. O servidor local iniciará e abrirá automaticamente no seu navegador em:  
   `http://localhost:3000/`

---

## 🌐 Como Publicar na Vercel (Online)

O projeto já inclui o arquivo `vercel.json` configurado com os rewrites de SPA.

1. Acesse [vercel.com](https://vercel.com)
2. Clique em **Add New Project**
3. Arraste a pasta `XS_PROSPECCAO_CLONE` ou importe pelo GitHub
4. Pronto! O sistema estará online com seu próprio domínio `.vercel.app`.

---

## 📦 Módulos e Páginas Incluídas

- **Prospecção & Busca de Empresas:** Módulo completo de busca de estabelecimentos no Google Maps (`/`, `/prospeccao`).
- **Agendamentos:** Gestão de retornos e reuniões (`/agendamentos`).
- **Disparos & WhatsApp:** Mensagens, funis e automações (`/whatsapp`).
- **CRM de Clientes:** Gestão de clientes fechados (`/clientes`).
- **Projetos:** Acompanhamento de entregas de sites (`/projetos`).
- **Financeiro:** Controle de faturamento e recebimentos (`/financeiro`).
- **Calculadora de Precificação:** Precificação de serviços digitais (`/precificacao`).
- **Estatísticas:** Métricas de conversão de prospecção (`/estatisticas`).
- **Configurações:** Perfil, tema claro/escuro (`/configuracoes`).
- **Planos & Assinatura:** Telas de planos e checkout Pix (`/assinar`).
- **Autenticação:** Login (`/entrar`), Cadastro (`/criar-conta`), Recuperação (`/esqueci-senha`).
